# 《古代汉语》文选、常用词、通论 AI 刷题库

> 王力《古代汉语》配套题库 · 纯前端 · 免后端 · 免注册

本项目是一个基于王力《古代汉语》（校订重排本）教材的 AI 辅助刷题网站，涵盖文选、常用词、通论三大板块，共 **1122 道题**（持续扩充中）。所有数据保存在浏览器本地，无需后端服务器，无需注册账号。

---

## 📖 简介

本题库基本按照课本的已学部分编制。工作流以网上搜集的题目和自己编写的题目作为样本提示，编写提示词，让大语言模型接入含有整理过课本原文的 RAG（检索增强生成）系统，仿照样本形式生成题目、正确答案、详细解析与知识回溯条目。

由于使用大模型生成，外加处理原始 PDF 教材时使用了 OCR（MinerU），题目表述或答案解析中可能出现少量错误，敬请理解。如发现错误或有建议，欢迎反馈。

## 🏗 技术架构

### 前端架构

| 层 | 技术实现 |
|:-----|:-----|
| 页面 | 纯 HTML + CSS + JavaScript，**零框架、零 CDN 依赖**，单文件自包含 |
| 交互 | 选项悬停放大、确认按钮按压反馈、页面切换滑入转场 |
| 音效 | Web Audio API 纯代码合成（点击音 / 答对上升双音 / 答错低沉蜂鸣），无音频文件 |
| 数据持久化 | 浏览器 `localStorage`：进度位置、正确/错误题数、错题池、收藏、生涯模式自动存档 |
| 富文本渲染 | 题干 / 选项 / 解析 / 知识回溯支持 Markdown 子集（表格、引用、列表、加粗、上下标、代码） |
| 公式渲染 | 可选 KaTeX（题库含公式时构建加 `--katex`，字体 base64 内联，仍保持离线单文件） |
| 部署形态 | 静态单页，双击可用，或托管于 GitHub Pages / 任意静态服务器 |

### 数据生成管线（题库来源）

本题库并非手工编写，而是由一条「OCR + RAG + LLM」的自动化管线产出：

```
王力《古代汉语》PDF 教材
  → ① OCR 文本化（MinerU 处理扫描件 / 排版，转为可检索的 Markdown 原文）
  → ② 建立 RAG 知识库（整理后的课本原文入库，供检索增强）
  → ③ 编写提示词（以网上搜集 + 自编题作样本提示，规定题型 / 格式 / 解析风格）
  → ④ LLM 生成（接入 RAG 检索课本原文，仿照样例输出题目）
  → ⑤ 人工复核（题目表述、答案、解析、知识回溯条目逐条校对后入库）
```

- **样本提示**：以真实样题规定格式与命题风格，保证生成结果符合题库标准
- **RAG 检索增强**：LLM 作答 / 出题时实时检索课本原文，降低凭空编造
- **知识回溯**：每条题目附带知识点位置索引，构成「知识点专项」刷题的数据基础

## 🎮 刷题模式

### 📖 专题模式

按三大板块（常用词／通论／文选）及其下子章节选择题目范围，进入后依次顺序答题。答完该章节全部题目后显示正确率统计。

- 中途按「← 返回」退出时会**自动保存当前进度**（答题位置、正确与错误题数）
- 下次进入同一子章节时会弹窗询问是否继续上次进度

### 🎲 随机模式

从所有题库中随机抽取题目，答完一题自动切换至下一题，永不重复。退出后进度不保留，适合碎片时间快速自测。

- 可选「**智能优先**」：根据已有作答数据，优先抽取薄弱知识点，数据不足时自动转为随机

### 🎯 生涯模式

所有题目随机排序依次出现。答对的题目**永久移除**，答错的题目移入错题池，待当前轮次完成后错题池重新打乱形成新一轮，直到全部题目都被答对才算通关。

- 每次答完一题即**自动存档**（localStorage）
- 关闭页面或中途退出后重新进入，直接从退出时的题目继续

### 📝 错题专项

集中消灭当前错题。错题池采用**掌握制**：任何模式答错即入池，任何模式答对即出池（考试交卷后的作答同样参与），全部答对后池子清空。

### 🏷️ 知识点专项

按「知识回溯」标签选择刷题范围，标签按章节分组以树状面板呈现，支持一次选择多个知识点合并成一个练习队列。

### 📋 考试模拟

模拟考试的作答体验：自定义题数，考试中**不即时判分**、可自由跳题，未答完不可交卷；交卷后统一结算（正确率 / 用时 / 题量）并支持只读复盘重看。

## ✨ 功能特色

### 答题操作

| 步骤 | 操作 |
|:----:|:------|
| ① | 点选你认为正确的选项（单选题点一个、不定项可选多个、判断题点「正确」或「错误」） |
| ② | 点击「确认答案」提交 |
| ③ | 查看正确答案标示与解析说明 |
| ④ | 点击「下一题」继续 |

### 三种题型

- **单选题** — 四选一，点选后确认
- **不定项选择题** — 可选多个选项，全部选对才计正确
- **判断题** — 点选「正确」或「错误」后确认

### 交互特色

- **答题卡抽屉** — 右下角一键展开，一览本轮作答情况，可跳转到任意题
- **题目收藏** — 题干右上角 ⭐ 一键收藏，首页「我的收藏」集中回看
- **音效反馈** — 点选选项有短促点击音，答对有上升双音，答错有低沉蜂鸣
- **视觉动效** — 选项悬停放大、确认按钮按压反馈、结果面板逐项揭开、页面切换滑入转场
- **连续答对提示** — 连续答对 3 题后显示「🔥 N 连对」
- **键盘快捷键** — 数字键选项、Enter 提交、方向键翻页、F 收藏
- **学习概览** — 首页显示已练进度、正确率、错题数，各模式卡片带数量徽标
- **完成页重练** — 答完一轮后可一键「重练本轮错题」

### 数据与隐私

- **所有数据存储在浏览器本地**（localStorage），不经过任何服务器
- **无需注册**，无需登录
- **无后端**，纯前端 HTML 单页应用
- 关闭页面后重新打开，进度仍然保留

## 📝 修订记录

### 2026-09 质量修订

对本题库做了一轮系统性质量校对与修正：

- **题量**：1141 → **1122 题**。合并了 19 道完全重复的题目（早期扩充题库时产生的副本），另有 1 道与外题题干重合作改写，成为独立题目
- **修复题目编号冲突**：全库存在 20 组题目 ID 重复（原 ID 由题干哈希生成），会导致两道不同的题**共用同一条作答记录**——做对其中一道，另一道会显示为已作答。已合并其中 19 组、改写 1 组
- **选项长度**：41 道单选题的选项长度差异过大（正确答案显著长于干扰项，最长者相差 26 字），已拉平至各选项颗粒度相当；修订后「正确答案为最长项」的比例由 95% 回落到 47%（接近随机基线）
- **不定项设计**：抽样改写了 10 道「四项全对」的题目，为其构造基于教材易混点的干扰项，恢复多选题的区分度
- **教材依据**：核对了各篇的册次归属（通论十三、十四 实出第二册），并统一了全库的用字
- **界面**：题面与界面语体统一为繁体（与题库一致），修正了此前界面文案为简体的问题
- **功能扩充**：刷题模式由三种扩充至**六种**（新增错题专项、知识点专项、考试模拟），并加入答题卡、题目收藏、学习概览、键盘快捷键等

> ⚠️ **进度提示**：本次修订改变了题目的内部 ID 与前端的本地存储标识，
> 因此**首次打开新版页面时，此前的刷题进度会重新开始**。题目内容与解析不受影响。
