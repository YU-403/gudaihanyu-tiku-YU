## Decisions Made

| 决策 | 理由 |
|:--|:--|
| 优先出课内内容 | 用户指定 |
| 题型照旧：單選 / 不定項 / 判斷，各约 1/3 | 与现有 32 章一致 |
| 题量基线：通論 25 題/章；常用詞 95 題/章；文選短篇 15–20、長篇 35–40 | 取自现有各章实际值 |
| 不定項全選率 ≤10% | 依 SKILL 规范；旧章 80% 全选的问题本次不动 |
| 首轮校准 10 題后再批量 | skill 默认要求，用户未要求跳过 |
| 顺序：通論 → 常用詞 → 文選 | 材料干净的先做，OCR 最脏的文選放最后 |
| 文選标题与标签加来源前缀（《詩經·關雎》《楚辭·哀郢》） | 专题列表里区分同名篇目；现有《禮記·大同》即此写法 |
| 「教材依據」写「第二冊 / 第四冊」 | 与册次事实一致，用字为繁体「冊」 |
| 全库繁体 | 与现有题库一致，界面语体自适配据此判定 |
| 詩律取材：教材通論为主，十講交叉印证，唐詩三百首仅作补充例证 | 用户要求优先课内 |
| 《七月》整篇覆盖（八章）不跳章 | 与《齊晉鞌之戰》等长篇章处理一致 |
| 常用詞每字 1–2 題 | 与常用詞一–四的实际密度一致 |
| 样本基准＝现有 1122 题，不另找真题 | 用户确认：暂无真题／教师练习题，以已出题目保持风格一贯性 |
| 风格提炼先于批量出题 | 先跑数据产出「口径卡」＋6 道标杆题，避免凭印象命题 |
| 新章不引入否定式设问 | 实测题库零使用「选出错误的一项」句式，保持一贯性 |
| 主题层用「构建后追加」，不用 `--custom-css` | 实测该参数注入点在样式表前部，覆盖类规则会被模板规则打败 |
| 主题层由机械差分抽取，不手工重写 | 330 行改动逐字保真；仅对 8 处结构断裂做修补 |
| 旧章既有的全选率 80% / 选项长度 148 处本次不修 | 本轮只保护主题，旧章问题另案处理 |

## Errors Encountered

| Error | Attempt | Resolution |
|-------|---------|------------|
| `--custom-css` 注入后覆盖失效 | 1 | 查 build.py 确认 `__STYLE_CSS__` 占位符在样式表前部，改用构建后追加 |
| 主题注释含字面量样式结束标签，致 `<style>` 提前闭合 | 1 | 改写注释措辞，并在 rebuild.ps1 加断言拦截 |
| rebuild.ps1 中文串在 PowerShell 5.1 下解析失败 | 1 | 脚本改为 UTF-8 with BOM；rebuild.bat 保持纯 ASCII |
| 重建后两处解析引用的选项字母与实际不符 | 1 | 解析改写为按内容指称，彻底摆脱选项顺序 |
